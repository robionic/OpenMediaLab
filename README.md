# OpenMediaLab

OpenMediaLab is an open-source, self-hostable web workbench for extracting and transforming media. Upload a local audio/video file or provide a direct media URL, YouTube link, or Vimeo link; select the operations you need; and preview or download the results in your browser.

## Features

- Local uploads and HTTP(S) direct media links; YouTube/Vimeo links through `yt-dlp`.
- Embedded browser preview of the source and produced audio/video.
- Selectable audio extraction as MP3 and/or OGG.
- Optional Whisper speech/lyric transcription to TXT, CSV, SRT, and VTT.
- Optional Demucs vocal/instrumental separation, exported as MP3 and/or OGG.
- Optional beat/BPM analysis and CSV/TXT beat timestamps.
- Optional timestamped frame extraction, with a ZIP of JPEGs and a CSV index.
- Optional MP4 and/or WebM video transcodes.
- Optional extraction of embedded subtitle tracks to SRT/VTT.
- Local-first storage. Jobs and media remain on the host running the app.

Whisper transcription, Demucs separation, and beat analysis use separately installed optional dependencies. Their models are downloaded on first use; the first request can take several minutes. CPU is supported, although slower. The base install works without AI dependencies, and selected unavailable features fail clearly instead of fabricating output.

## Requirements

- Python 3.10 or newer.
- FFmpeg and FFprobe available on `PATH` (for example, install the FFmpeg package for your OS).
- Optional: install the `ai` extra for Whisper, Demucs, and beat detection. PyTorch installation and model execution may require extra disk space and memory.
- Python 3.11 is a good starting point for the optional AI stack; PyTorch support can lag the newest Python releases.
- On Windows, install FFmpeg with `winget install --id Gyan.FFmpeg --exact`, then restart your terminal so the updated `PATH` is available.

## Run locally

From the project directory:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
# For transcription, source separation, and beat analysis:
python -m pip install -e ".[ai]"
python -m uvicorn openmedialab.main:app --reload
```

Open <http://127.0.0.1:8000>. On macOS/Linux, activate the virtual environment with `source .venv/bin/activate`.

Set `OPENMEDIALAB_STORAGE_DIR` to choose another data directory,
`OPENMEDIALAB_MAX_UPLOAD_BYTES` to change the upload/download size cap, and
`OPENMEDIALAB_MAX_FRAMES` to adjust the maximum number of extracted frames.
Defaults are `./data`, 1 GiB, and 1,000 frames. `.env.example` lists the settings.
Do not expose an unauthenticated instance to the public internet.

On managed Windows devices, Application Control may block FFmpeg or native AI runtime libraries. If a binary is blocked, ask your administrator for an approved build; do not bypass the device policy.

## Design and safety

- Direct links must be public HTTP(S) media URLs. Private/local IPs and redirects to them are rejected. YouTube and Vimeo links are restricted to their known public domains.
- Downloads and uploads are bounded by the configured byte limit. Frame extraction is bounded separately.
- Media commands use argument arrays rather than a shell. Output filenames are generated by the application; original uploaded filenames are never used as filesystem paths.
- Jobs are processed locally by the web process. This is intended for a trusted, single-user/local deployment, not as a multi-tenant service. There is no authentication or background worker queue yet.
- Source media and job data are retained under the storage directory until manually removed by the operator.
